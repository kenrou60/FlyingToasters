# FlyingToasters Screensaver

Windows 用の Flying Toasters スクリーンセーバーです。  
インストーラー付きで簡単に導入できます。

最新バージョンは GitHub Releases からダウンロードできます。

👉 https://github.com/kenrou60/FlyingToasters/releases

- `scr_setup.exe`（署名済みインストーラー）
- `FlyingToasters.scr`（署名済みスクリーンセーバー本体）

---

## 🖥 対応 OS

- Windows 10  
- Windows 11  

---

## 🛠 インストール方法

1. `scr_setup.exe` を実行  
2. インストール完了後、  
   **設定 → 個人用設定 → ロック画面 → スクリーンセーバー**  
   から「FlyingToasters」を選択してください。
